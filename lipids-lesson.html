Клинический разбор

Применение знаний к реальной ситуации

К врачу-диетологу обратилась пациентка, 28 лет. Жалобы: сухая шелушащаяся кожа, ломкие ногти, постоянная усталость, плохое заживление мелких ран. Зимой постоянно мёрзнет даже в тёплой одежде.

Она сидит на строгой диете: исключила все жиры. Ест только обезжиренные продукты, каши на воде, овощи, куриную грудку, хлеб без масла.
Вопрос 1 / 3
Какое наиболее вероятное функциональное нарушение можно предположить?
Верно! Пациентка исключила все жиры, а её симптомы (сухая кожа, плохое заживление, зябкость) напрямую связаны с функциями липидов. Дефицит углеводов дал бы слабость, но не сухость кожи. Белки — мышцы и иммунитет. Гипервитаминоз здесь ни при чём.
Вопрос 2 / 3 · Можно выбрать несколько
Какие функции липидов нарушены у пациентки?
✓
🧱 Структурная — кожа и мембраны клеток обновляются медленнее
✓
🌡 Теплоизоляционная — зябнет из-за нехватки подкожного жира
✓
💧 Водоотталкивающая — сухая кожа теряет влагу
✓
📡 Регуляторная — холестерин нужен для синтеза гормонов
✓
🛡 Защитная — жировая прослойка вокруг органов
Правильно! Все перечисленные функции нарушены. Структурная — мембраны клеток кожи не обновляются. Теплоизоляционная — нет подкожного жира. Водоотталкивающая — кожа сухая. Регуляторная — холестерин нужен для гормонов. Защитная — нет жировой подушки вокруг органов.
Вопрос 3 / 3 · Дневник питания
Какой приём пищи нужно скорректировать в первую очередь?
ПриёмБлюдо
ЗавтракОвсяная каша на воде, зелёный чай
ОбедСалат из капусты и моркови (без масла), куриная грудка
ПолдникЯблоко
УжинГречка (без масла), овощное рагу, хлеб
Абсолютно верно! Растительное масло — источник ненасыщенных жирных кислот. Это поможет улучшить состояние кожи (структурная функция), начать усваивать витамины A, D, E, K и дать организму сырьё для гормонов. Замена чая (А) не связана с липидами. Убрать яблоко (В) — вредно. Свинина (Г) добавит жиры, но лучше начинать с растительных.
